Modern Navigation, Made Simple. Beautiful, lightweight, and modular navigation system specifically designed for Health and Healthcare websites. Integrates seamlessly with Elementor Free.

== Description ==

Navora is a performance-first WordPress plugin designed to solve the limitations of standard menus in Elementor Free. Built with modern visual guidelines for Health, Medical, and Wellness websites.

Key Features:
*   **Modern Design (2026 standard)**: High-quality layouts designed for healthcare clinics, dental practices, pharmacies, and wellness centers.
*   **Performance First**: Completely static assets (minimized JS/CSS), inline CSS variables for seamless caching/CDN support (Cloudflare, FlyingPress, Perfmatters compatible).
*   **Elementor Free Integration**: Native Elementor widget (no Pro required) and a simple shortcode `[navora_menu]`.
*   **Responsive drawer navigation**: Touch-friendly, accessible mobile menu drawer.
*   **Clean Admin Options**: Simply select your WordPress menu, customize colors, upload your logo, and turn on sticky navigation.

== Installation ==

1. Upload the `navora` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **Settings > Navora** to configure your logo, menu, layout, and colors.
4. Insert the menu using the Elementor Widget "Navora Menu" or via the shortcode `[navora_menu]`.

== Frequently Asked Questions ==

= Does it require Elementor Pro? =
No, Navora works perfectly with Elementor Free.

= Does it conflict with caching plugins? =
No. Navora uses inline CSS custom properties (CSS variables) for user settings, so the main CSS file is static and fully cacheable by CDNs, Cloudflare, FlyingPress, and Perfmatters.
